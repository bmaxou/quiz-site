RAADS-14 Screen : repérage des traits autistiques chez l'adulte

14 affirmations sur votre vécu, à noter selon qu'elles sont vraies maintenant, avant 16 ans, les deux ou jamais. Auto-questionnaire de repérage, à compléter de préférence avec un professionnel.

Please choose one of the following alternatives: This is true or describes me now and when I was young. This was true or describes me only now (refers to skills acquired). This was true only when I was young (16 years or younger). This was never true and never described me. Please answer the questions according to what is true for you. Check only one column per statement!
