QLQ-BR23 — Module cancer du sein de l'EORTC

Les patientes rapportent parfois les symptômes ou problèmes suivants. Pourriez-vous indiquer, s'il vous plaît, si, durant la semaine passée, vous avez été affectée par l'un de ces symptômes ou problèmes.

Version française officielle (« French (Europe) »). Outil sous licence (EORTC Quality of Life Group) : « Licence requise : oui ».

23 questions 5 minutes 8 scores de 0 à 100

Résultat

Le module comporte huit scores de 0 à 100, calculés selon le manuel de cotation de l'EORTC.

Échelles fonctionnelles (plus le score est élevé, meilleur est le fonctionnement ; pour les perspectives d'avenir, plus le score est élevé, moins l'inquiétude est grande)

Échelles de symptômes (plus le score est élevé, plus les symptômes sont importants)

Aucun seuil clinique officiel n'est repris ici : ces scores se lisent avec la patiente, et de préférence en comparaison de ses scores antérieurs. Ce module complète le questionnaire de base QLQ-C30 (questions 1 à 30), non inclus dans cette page.
